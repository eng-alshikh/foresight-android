# Foresight — AI Meeting Notes

This repository publishes the public website and the legal documents for
**Foresight — AI Meeting Notes** (`com.xenolabs.foresight`), an on-device AI meeting
assistant for Android.

| Page | URL |
|---|---|
| Overview | <https://eng-alshikh.github.io/foresight-android/> |
| Privacy Policy | <https://eng-alshikh.github.io/foresight-android/privacy.html> |
| Terms of Service | <https://eng-alshikh.github.io/foresight-android/terms.html> |
| Account & Data Deletion | <https://eng-alshikh.github.io/foresight-android/delete-account.html> |

The pages are served by GitHub Pages from the `main` branch of this repository.
`privacy.html`, `terms.html` and `delete-account.html` are the exact URLs the Android
application links to from **Settings → Legal notices** and from the privacy information
dialog, so they are the authoritative copies of the published legal documents.

## About the application source

The application source is **not** published here and is kept in a private repository.
This repository holds only the public-facing site and the legal documents that the app
and the Play Store listing point at.
